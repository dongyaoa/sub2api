# 接入文档模块

独立的静态只读模块，通过 `/integration-docs` 接入用户控制台。无需新增后端接口、数据库、模型调用或在线编辑配置。外部集成点仅为路由、侧栏和页面标题翻译；布局、图标、复制反馈与主题复用宿主项目。

## 内容维护

- `content/chat.md`：对话模型（首个栏目），包含 CC-Switch 接入 Codex、Claude Desktop 配置及对话 API 示例。
- `content/image.md`：图片生成，包含模型参数、文生图、图片编辑和异步任务说明。
- `content/video.md`：视频生成，包含各模型参数、统一任务接口和调用示例。
- `content/speech.md`：语音合成，包含音色、单双人合成和音频响应说明。

每个文件使用一个一级标题、若干二级标题；二级标题自动成为栏目内的小目录，正文内部使用三级或更低层级。代码围栏中的标题不会被误认为目录。栏目完整源文件用于 Markdown 下载，搜索与当前章节不会改变导出范围。更新内容时同步核对模型、接口路径、参数和示例；公开文档仅放占位 API Key。

## 模块结构

`catalog.ts` 负责栏目与章节、搜索和选中项回退；`markdown.ts` 负责独立 Markdown 渲染及 HTML 清理；`IntegrationDocsView.vue` 负责阅读导航、代码复制和栏目导出；`docs.css` 的样式限制在本模块。文档通过 `?raw` 随路由懒加载，运行时不读取附件所在磁盘，也不拉取远程文档。

页面 URL 的 `category` 和 `section` 查询参数支持刷新、分享与浏览器前进后退；非法参数回退到有效的首个章节。默认展开全部栏目，移动端通过“文档目录”按钮查看目录。正文保留中文技术资料，操作控件支持中英文。
